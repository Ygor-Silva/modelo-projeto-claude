# Modelo de projeto (Claude Code)

Repositório-modelo para começar projetos novos já com o **Diário de Tarefas** ligado,
inclusive nas sessões do Claude Code na web (claude.ai/code).

## Como usar

1. No GitHub, clique em **Use this template** → **Create a new repository**.
2. Abra o repositório novo no Claude Code (web ou computador).
3. Digite `/diario` para ver o painel; `/andamento` dá o status para o gestor.

O arquivo `.claude/settings.json` é o que liga o Diário. Se o projeto já tiver esse arquivo,
copie para ele os blocos `extraKnownMarketplaces` e `enabledPlugins`.

O mod vem do repositório privado `Ygor-Silva/claude-mod-diario-tarefas`: a integração do
Claude com o GitHub precisa ter acesso a ele.
